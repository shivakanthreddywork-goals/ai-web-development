# AI Web Development Portfolio Projects

Three GitHub-ready portfolio projects for learning and demonstrating AI-powered website and web application development.

## Projects
1. **ai-website-copy-studio** — generate landing-page and website copy.
2. **ai-customer-support-chat** — a FastAPI chat web application.
3. **ai-resume-match-analyzer** — compare resume text with a job description.

Each project includes source code, prompt templates, setup instructions, `.env.example`, and demo mode. No API key is needed to try the basic functionality.

## Upload to GitHub
Create a separate repository for each project and upload the contents of its folder. Keep API keys in a local `.env` file and never commit secrets or private user data.

These are portfolio starters, not production systems. Review and customize them before real-world use.
